AI Inference

From Conversation → Structured Evidence

Deterministic Contracts
Input Context Injection:

Prompt explicitly passes `question_id`, conversation phase, and strict JSON instruction. Open-ended speculation is penalized.

Evidence Extraction Contract:

Every detected stress signal must be backed by literal verbatim text in the `evidence` field. If no evidence exists, confidence falls to 0.

Validation Layer:

Pydantic / TypeScript validator checks schema before state updates. Unparseable JSON triggers retry or fallback.

// Validated Output from NVIDIA NIM
{
  "question_id": "Q04",
  "response_status": "direct_answer",
  "stress_indicators": [
    {
      "indicator": "fear_of_retaliation",
      "severity": "moderate",
      "evidence": "I am scared whenever I see him."
    }
  ],
  "confidence": 0.91,
  "needs_clarification": false
}

The model cannot alter assessment weights, reset phases, or bypass validation checks.

Safety Architecture

When the Conversation Becomes a Safety Issue

Deterministic Triage
Tier 1: Normal Distress

Stress, tears, workplace agitation.

→ Standard empathetic chat + somatic grounding.
Tier 2: Passive Death Remarks

"I wish I didn't wake up", "Everything is too heavy".

→ Gentle safety clarification prompt without panic.
Tier 3: Suicidal Ideation

Self-harm intent or explicit despair.

→ Crisis intervention mode; Tele-MANAS (14416) & 14566 cards.
Tier 4: Imminent Danger

Perpetrator on premises / immediate physical violence.

→ Immediate Emergency 112 overlay & discreet Quick Exit.
Safety routing completely supersedes LLM generation. When Tier 3/4 triggers, generative responses are halted.

Fault Tolerance

What Happens When AI Is Wrong?

Fail-Safe Engineering
Model Failure Modes & Recovery
  • • Schema Malformation: Caught by validator; prompts silent single retry or falls back to empathetic response.
  • • Hallucinated Evidence: Extracted quotes checked against raw transcript. Unmatched quotes rejected.
  • • Low Confidence (<0.60): State engine marks `needs_clarification = true` and asks gentle clarifying query.
Hardware & Infrastructure Degradation
  • • NIM API Outage / 500: Catches error gracefully, returns calming pre-compiled response, preserves session state.
  • • Camera Hardware Lockout: Progressive fallback (`ideal` → `facingMode` → text mode without crashing).
  • • Browser STT Unsupported: Graceful detection, disables mic, prompts user to type softly.
Zero Hard Failures: The victim is never shown raw error codes, broken stack traces, or abandoned sessions.
